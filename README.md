# 🎟️ TicketDrop

> Открывай боксы. Собирай моменты. Прокачивай коллекцию.

**TicketDrop** — браузерная коллекционная игра, где каждое открытие бокса превращается в маленькое событие. 
Кликай, выполняй задания, зарабатывай билеты — и открывай карточки, 
собранные вокруг реальных моментов жизни: от «Утра понедельника» до «Победы над кодом».

## ✨ Что внутри

- 📦 **Боксы с рандомом** — каждая карточка падает по шансам редкости
- 🎟️ **Билеты** — открытие стоит 3 билета, их дают за клики и задания
- 🪙 **Кликер** — кликай по монете → EM и билеты капают сами
- 🃏 **Коллекция** — все карточки с описаниями и фильтрами по пакам
- 📋 **Задания** — прогресс за клики, боксы, собранные карточки
- ⚡ **Апгрейды** — усиливают клик, билеты и шанс редкой карточки
- 🏆 **Достижения** — тосты, звуки, частицы на каждом важном событии
- 💾 **localStorage** — весь прогресс сохраняется в браузере

## 🎨 Дизайн

Тёмно-синий премиум-стиль с акцентами на циан и фиолет. 
Сетка-паттерн на фоне, мягкие свечения, плавные анимации. 
Вдохновение — Linear, Vercel, Arc Browser.

## 🚀 Технологии

- **Vanilla JS** — без фреймворков и сборщиков
- **CSS3** — Grid, Flexbox, custom properties, анимации
- **Canvas API** — система частиц
- **Web Audio API** — звуковые эффекты
- **localStorage** — сохранение прогресса
- **GitHub Pages** — хостинг

## 🎯 Философия

TicketDrop — не про «задротство» и бесконечный гриндинг. 
Это про **маленькие радости**: открыть бокс в обед, поймать редкую, 
собрать полную коллекцию будней разработчика. 
Каждая карточка — кусочек настроения, а не просто пиксели.
